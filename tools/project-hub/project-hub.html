The nine build phases

How work is saved (your Git rule)

  • Two branches: development for all work, production for the live site.
  • A checkpoint is saved before every phase starts.
  • Nothing is ever sent straight to production. It only changes by merging development after a code review. This is enforced on this computer.
  • Passwords and keys stay in a private settings file that is never saved to Git.
